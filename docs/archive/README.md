# Historical Docs Archive

Estos documentos se conservaron como referencia historica, pero ya no forman parte del camino principal de operacion o mantenimiento del repo.

Regla practica:

- si un documento describe una fase cerrada y no tiene enlaces activos desde la documentacion vigente, vive aqui;
- si vuelve a ser relevante, debe reingresar al indice vivo con una referencia explicita.
